# A Python entry script inside a model repository

Measured with litert-lm-api 0.18.1 and ai-edge-litert 2.3.0 in a fresh virtual environment (Python 3.12), running [litert-community/LFM3-Omni-2B-LiteRT](https://huggingface.co/litert-community/LFM3-Omni-2B-LiteRT)'s `examples/run_omni.py` from an upload stage made of file symlinks. The Hugging Face cache lays out a downloaded snapshot the same way: each file is a symlink into a blob store.

- **Find the repository root with `os.path.dirname(os.path.abspath(__file__))`.** `Path(__file__).resolve()` follows the script's symlink to where the file really lives, and the script then looks for the model and its other files next to that file, not next to the link.
- **Pass `cache_dir=":nocache"`, or a writable directory you choose.** With an empty `cache_dir`, LiteRT-LM 0.18.1 writes its caches next to the model file, which is inside the snapshot (a 1.73 GB GPU weight cache and a 23 MB GPU program cache from one earlier GPU run; with `":nocache"` no new file appeared).
- **Catch the bare error of `send_message`.** When `Conversation.send_message` fails, LiteRT-LM prints the reason on an `E` log line and then raises `RuntimeError("litert_lm_conversation_send_message failed")`, which has no reason in it. Catch it, point the user at the log line above, and close the conversation in `finally`: a conversation left open prints `EngineAdvancedImpl destructed with 1 living sessions!` at exit.
- **`litert_lm.set_min_log_severity(LogSeverity.ERROR)` quiets LiteRT-LM only.** Its INFO and W lines go; graphs run through ai-edge-litert's CompiledModel (here the speech graphs) still print INFO lines and a W line from `npu_registry.cc`.
- **Check the inputs before the runtime does.** The example takes 16 kHz mono 16-bit PCM WAV and PNG or JPEG pictures. LiteRT-LM reads a recording longer than 30 s in 30 s windows with no overlap, one audio-encoder call each, until the context is full: a 502 s recording stopped at 6,307 tokens against a 4,096-token context.
