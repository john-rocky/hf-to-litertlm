## 1. Put the model files in place

```
python3 tools/play_ai_pack/make_ai_pack.py fetch --out <this dir>            # downloads + sha256 check
python3 tools/play_ai_pack/make_ai_pack.py fetch --out <this dir> --local-file <file>.litertlm=/path/to/copy
```

## 2. Build the app bundle

```
cd <this dir>
gradle wrapper --gradle-version {{GRADLE}}     # once; or open the folder in Android Studio
./gradlew :app:bundleRelease
ls app/build/outputs/bundle/release/app-release.aab
```

Upload signing: export `PLAY_UPLOAD_KEYSTORE`, `PLAY_UPLOAD_STORE_PASS`, `PLAY_UPLOAD_ALIAS`,
`PLAY_UPLOAD_KEY_PASS` before `bundleRelease` (create a keystore once with `keytool -genkeypair`).

## 3. Test locally with bundletool ({{BUNDLETOOL}}+)

```
java -jar bundletool-all-{{BUNDLETOOL}}.jar build-apks --bundle=app/build/outputs/bundle/release/app-release.aab \
    --output=out.apks --local-testing --overwrite
java -jar bundletool-all-{{BUNDLETOOL}}.jar install-apks --apks=out.apks --device-groups=<one of {{GROUP_NAMES}}>
adb shell pm path {{APPLICATION_ID}}      # shows split_main_{{PACK_NAME}}.config.group_<g>.apk for install-time packs
adb logcat -s AiPackTest
```

`--device-groups` names the group the attached phone should be treated as; local testing does not
evaluate the selectors. Fast-follow packs behave as on-demand under local testing (tap the button).
Uninstall before installing a new build; updates are not supported locally.

## 4. Internal test on Google Play

1. Play Console → the app (`{{APPLICATION_ID}}`) → Testing → Internal testing → create release → upload the `.aab`.
2. Add tester accounts, share the opt-in link, install from Play on each test device.
3. Open the app, tap **Fetch pack and run**. The screen shows brand/device, `Build.SOC_MANUFACTURER SOC_MODEL`,
   RAM, the group and file the device received, the sha256 check, load time and the reply.
4. Compare the file + sha256 against `plan.json`; a device that shows the index instead of a model
   matched no group (it received the default, empty variant).

Selector strings (`brand`/`device`, SoC manufacturer/model) are only evaluated by Play itself; the Console's
Device Catalog is the reference for the exact spelling.
